# UI STAR — student home (prototype)

Clickable HTML prototype of the STAR student home and courses pages. Plain HTML/CSS/JS, no build step, no dependencies.

- `index.html` — Home
- `courses.html` — Courses
- `copy.js` — **all wording** lives here; edit it to change any text
- `kit.js` / `kit.css` — shared code and styles (settings such as loader timing are in `CONFIG` at the top of `kit.js`)

Open `index.html` in a browser, or serve the folder (`python -m http.server`).
